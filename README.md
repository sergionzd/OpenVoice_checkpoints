# OpenVoice_checkpoints
Checkpoint files for the Open Voice repo. Incredibly hard to find or generate.
The original repo for the Open Voice can be found here: https://github.com/myshell-ai/OpenVoice
After mucking around with voice implementations for the Qwen models I used Claude to do research and search of components necessary to make the job done.
All updates on the Open Voice implementation I intend to push here.
